## ✨ Visão Geral

Este projeto foi desenvolvido como parte do curso **"Kotlin: Crie sua primeira aplicação"**. O objetivo principal foi aplicar os conceitos fundamentais da linguagem Kotlin para criar uma aplicação de console que interage com uma API externa para buscar informações sobre jogos.

A aplicação permite ao usuário:
1. Buscar jogos pelo ID.
2. Criar e gerenciar um perfil de "Gamer".
3. Manter uma lista de jogos buscados.

## 🛠️ Tecnologias e Conceitos Utilizados

* **Linguagem:** Kotlin
* **IDE:** IntelliJ IDEA
* **Gerenciador de Dependências:** Maven
* **Consumo de API:** `HttpURLConnection` / `HttpClient` (implementação de requisições HTTP)
* **Manipulação de JSON:** `Gson` (Desserialização de dados)
* **Conceitos de Linguagem:**
    * `var` vs `val`
    * Data Classes
    * Tratamento de Exceções (`try/catch`, `runCatching`)
    * Scope Functions (`let`, `run`, `apply`, `also`)
    * Extension Functions
    * Companion Objects
    * Validação de dados (Expressões Regulares - Regex)
